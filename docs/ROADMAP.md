# Roadmap

## 0.1 — Local MVP

- project dashboard;
- category/search filters;
- project detail;
- status and progress updates;
- decision log;
- timeline;
- public preview;
- browser persistence.

## 0.2 — Durable workspace

- authentication;
- hosted database;
- project ownership;
- CRUD API;
- link management;
- import/export;
- responsive polish.

## 0.3 — GitHub context

- GitHub OAuth;
- repository linking;
- releases and commits in the timeline;
- optional README/devlog generation;
- sync boundaries that do not turn Nodi into another issue tracker.

## 0.4 — Public project pages

- shareable slugs;
- custom visibility;
- milestones and release history;
- project screenshots/assets;
- simple analytics.

## Later

Collaboration, paid plans and AI summaries only after the core project-history workflow is validated with real usage.
